# J'ETAM – Live Show 2025

Intégration d'une page événement à partir d'une maquette Figma, en version desktop et mobile.

## Lancer le projet

```bash
npm install
npm run dev      # serveur de développement : http://localhost:5173
npm run build    # version de production dans /dist
```

## Stack

- HTML5 sémantique
- SCSS (méthodologie BEM, architecture en dossiers)
- TypeScript
- Vite
- Polices auto-hébergées avec Fontsource (Inter, Marcellus)
